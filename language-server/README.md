# Kit LSP

Placeholder VSCode extension for the [Kit](https://kitlang.org/) language server
(`kitlang.lsp`).

This extension currently contributes **sample configuration options only** and
does not yet start a language server. The real server will be wired in later.

## Configuration

- `kitlang.lsp.enable` — enable the language server (default `true`)
- `kitlang.lsp.serverPath` — path to a custom server binary (default `null`)
- `kitlang.lsp.trace` — LSP trace level: `off` | `messages` | `verbose`
- `kitlang.lsp.telemetry` — allow anonymous usage data (default `false`)
